# CLAUDE.md

This file gives Claude Code basic rules for working in this project.
Also read `AGENTS.md`. It has the shared instructions for all AI agents.

## Project

`claude-practice` is a practice project for learning how to work with Claude Code.

## Most Important Rule

**Always ask before doing anything.** Never act on your own. Get the user's permission before every change, small or big: editing files, creating files, running commands, commits, everything. Do only what was asked. If you think something extra is needed, suggest it and wait for a "yes".

## Basic Rules

1. **Keep it simple.** Write clean, readable code. Don't over-engineer.
2. **Small changes.** Change only what is asked. Don't refactor unrelated code.
3. **Read before editing.** Understand the existing code before you change it.
4. **Match the style.** Follow the naming, formatting, and patterns already in the project.
5. **Clear names.** Use meaningful names for variables, functions, and files.
6. **Comments only when needed.** Explain *why*, not *what*.
7. **No secrets in code.** Never commit API keys, passwords, or `.env` files.
8. **Test your work.** Run the code or tests after a change to make sure it works.
9. **Ask when unsure.** If the request is unclear, ask before making big changes.
10. **Git safety.** Don't commit or push unless asked. Never force-push to `main`.

## Communication

- The user may write in Roman Urdu or English. Reply in the same language they use.
- Keep explanations short and simple.
