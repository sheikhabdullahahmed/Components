# Claude Practice

A simple practice project for learning how to use [Claude Code](https://claude.com/claude-code).

## What's inside

| File        | Purpose                                              |
|-------------|------------------------------------------------------|
| `AGENTS.md` | Instructions for any AI coding agent (Codex, Cursor, etc.) |
| `CLAUDE.md` | Basic rules Claude follows when working in this repo |
| `README.md` | This file: overview of the project                   |

## How to use

1. Open this folder in a terminal.
2. Run `claude` to start Claude Code.
3. Ask Claude to build or change something. It reads `CLAUDE.md` automatically and follows those rules.

## Editing the rules

Open `CLAUDE.md` and add, remove, or change rules as the project grows,
for example your tech stack, how to run tests, or folder structure.
